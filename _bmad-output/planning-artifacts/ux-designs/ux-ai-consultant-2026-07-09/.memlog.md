updated: 2026-07-09T09:27

- (decision) UI system: shadcn/ui on Next.js + Tailwind — brand-layer delta pattern. Inherit shadcn defaults for all unlisted components.
- (decision) Form factor: desktop web primary. Dev View (local mode only) disabled on md and sm breakpoints.
- (decision) Dark mode as primary/default. Colors: Primary Indigo (#4F46E5 / #818CF8), Agent Active Amber (#F59E0B), Success Emerald (#10B981), Log Surface (#0D1117).
- (decision) Ticket cards are inline in the chat scroll surface — not a sidebar or modal. Conversation is the product.
- (decision) Chat input disabled during active execution. SSE-only updates — no polling anywhere.
- (decision) Mono font (Geist Mono) for all agent output, log streams, ticket IDs, spec previews, cost indicator. Mono = machine output.
- (decision) Cost indicator always visible — shows 0 tokens / .00 when no usage. Never hidden.
